Permission rule

Connecting a service does not give every AI request automatic access. HOPE should request only the capability needed for the task, and sensitive write actions should use explicit confirmation where appropriate.

OAuth providers open their real authorization flow. Services that require developer credentials use the encrypted credential vault. AI Hub will never display a fake “Connected” state.
